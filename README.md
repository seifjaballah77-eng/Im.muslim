# i-Muslim | رفيق المسلم

تطبيق إسلامي عربي-first يعمل كتطبيق ويب تقدمي (PWA)، ومصمم للهاتف والكمبيوتر.

## النسخة الحالية
- واجهة عربية RTL بتصميم أخضر داكن ولمسات ذهبية.
- مواقيت الصلاة عبر خدمة AlAdhan بعد السماح بالموقع.
- حساب زاوية القبلة من إحداثيات الجهاز.
- فهرس القرآن وعرض السور عبر AlQuran Cloud.
- أقسام أولية للأذكار والمسبحة والتقويم الهجري.
- حفظ عدد التسبيح محلياً.
- أساسيات التثبيت والعمل دون اتصال لملفات التطبيق.

## التشغيل
يمكن نشر المستودع عبر GitHub Pages من Settings → Pages واختيار فرع `main` ومجلد `/(root)`.

## ملاحظات مهمة
- يلزم HTTPS للسماح بخدمات الموقع وتثبيت PWA؛ GitHub Pages يوفر HTTPS.
- بيانات المواقيت تعتمد على طريقة الحساب التي توفرها الخدمة، ويجب إضافة إعدادات المدينة وطريقة الحساب للمستخدم.
- الاتصال بالإنترنت مطلوب لجلب بيانات القرآن والمواقيت والتاريخ في هذه النسخة.
- محتوى الأحاديث والأحكام الشرعية لم يُفعّل بعد؛ لن يُضاف قبل ربط مصادر موثوقة والتحقق من التخريج والمراجعة.
- هذا إصدار تأسيسي، وليس إصداراً نهائياً. يلزم اختباره على الهاتف والكمبيوتر قبل اعتباره جاهزاً.
